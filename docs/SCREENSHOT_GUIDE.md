# Screenshot Guide

Capture these for GitHub, LinkedIn, and your resume portfolio:

1. Admin upload panel with multiple documents selected.
2. Successful ingestion response showing number of documents and chunks.
3. Query answer view with citations expanded.
4. Latency and citation count metrics in the dashboard.
5. Architecture diagram screenshot or exported figure.
6. Benchmark table comparing dense, keyword, hybrid, and reranked retrieval.

Recommended caption style:

- `Hybrid retrieval with source-grounded enterprise QA`
- `Citation-first answer generation with validation notes`
- `Benchmarking retrieval quality using Recall@K and MRR`
